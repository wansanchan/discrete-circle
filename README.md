# 指向曲率中心的离散圆

寻求审阅与 Lean 形式化。本仓库不包含 Lean 工具链。

闭合多边形的有效能量 \(V_N\) 只惩罚不等边、不等外角、法线不经过由这些边自己算出的质心。圆心不是预先放入的点。

请核对两则陈述。

1. 在凸、绕数 \(w=1\)、边长为正、外角在 \((0,\pi)\) 的分支上，\(V_N\ge 0\)，且 \(V_N=0\) 当且仅当多边形正则（模平移、转动）。此时各边中点法线交于一点，该点是质心也是内心。
2. 定义 \(\pi_{\mathrm{eff}}=P^2/(4A)\)。正则时 \(\pi_{\mathrm{eff}}=N\tan(\pi/N)=\pi+\pi^3/(3N^2)+O(N^{-4})\)。

另有一则独立短论：若可区分距离有最小值 \(\ell>0\)，则半径 \(R\) 的可实现圆是正 \(N\) 边形，\(N=\lfloor\pi/\arcsin(\ell/(2R))\rfloor\)，矢高约为 \(\ell^2/(8R)\)。

不在本仓库范围内的主张：该能量不是从 Thiemann 约束推导出来的；这个图像没有给出现有仪器能单独认领的信号；与黎曼猜想无关。
